## 8. How the classification works

Regex rules in `.agents/scripts/scan-inline-scripts.cjs`. Precedence, top wins:

1. **D** — a third-party signature (gtag, fbq, Tawk_API, grecaptcha, Pusher, Stripe, PayPal, Razorpay)
2. **A** — a widget constructor (`new Swiper`, `.DataTable(`, `.select2(`, `.summernote(`,
   `flatpickr(`, `new ApexCharts`, `new Dropzone`, `.modal(`, `switchButton(`, `.steps(`, …)
3. **A** — a `document.ready` / `DOMContentLoaded` wrapper that also queries the DOM by class or id
4. **B** — `$.ajaxSetup(`, `$(document).on(`, `window`/`document` `addEventListener`, or
   `window.X = ` together with a function declaration
5. **C** — only variable assignments, ≤12 lines, no DOM work and no AJAX
6. **B** — function declarations with no ready wrapper (hoisted helpers)
7. **E** — anything left

`mixed` is set when an A block also contains delegation, `ajaxSetup`, or a global listener.
