### প্রেক্ষাপট

Hotwired Turbo Drive বসানো হয়েছে (CLAUDE-5)। Turbo পেজ reload না করে body
swap করে। ফলে `$(document).ready()` শুধু প্রথম লোডে চলে — পরের পেজে চলে না।

Claude তিনটি global helper দিয়েছে (`resources/js/turbo-bootstrap.js`)।
layout-এ একটি stub আছে, তাই bundle লোড হওয়ার আগেই inline script এগুলো
ডাকতে পারে — "not a function" error হবে না:

```js
window.onTurboLoad(fn)      // প্রতি পেজে একবার — widget init (DataTable, select2)
window.onTurboOnce(fn, key) // পুরো সেশনে একবার — event delegation
window.onTurboUnload(fn)    // পেজ cache হওয়ার আগে — destroy
```

### রূপান্তরের নিয়ম

**নিয়ম A — `$(document).ready(function () { ... });` পেলে:**

আগে:
```
@push('custom-script')
<script>
    $(document).ready(function () {
        $('.select2').select2();
    });
</script>
@endpush
```
পরে:
```
@push('custom-script')
<script>
    window.onTurboLoad(function () {
        $('.select2').select2();
    });
</script>
@endpush
```

**নিয়ম B — `$(function () { ... });` পেলে:**
একইভাবে `window.onTurboLoad(function () { ... });`

**নিয়ম C — `$(document).on('click', 'selector', ...)` (event delegation):**

এটি ONCE-ONLY। মোড়াবে:
```
window.onTurboOnce(function () {
    $(document).on('click', '.code', function () { ... });
});
```

🔴 **এটি সবচেয়ে গুরুত্বপূর্ণ নিয়ম।** না মানলে যা হয় তা মাপা হয়েছে:
`document`-এ click handler **২৯ → ৪৬৪** (৮ navigation), এবং একটি
add-to-cart ক্লিকে **৮টি POST /product_cart** — DB-তে qty ১ → ৮।

⚠️ যদি block-এ Blade মান interpolate করা থাকে (`{{ $x }}`), তাহলে প্রতি পেজে
source text আলাদা হয় এবং duplicate detection কাজ করে না। সেক্ষেত্রে দ্বিতীয়
আর্গুমেন্টে একটি নাম দাও:
```
window.onTurboOnce(function () { ... }, 'cart-delegation');
```

**নিয়ম D — খোলা script (কোনো ready wrapper নেই, সরাসরি কোড):**
DOM element খুঁজে init করে (`$('.x').something()`) → `window.onTurboLoad(...)`
দিয়ে মোড়াও।
শুধু variable declaration (`var site_url = "...";`) → **স্পর্শ করবে না**।

**নিয়ম E — একই script-এ A এবং C দুইটাই মিশে আছে (mixed):**
দুইটা আলাদা block-এ ভাগ করো — delegation অংশ `onTurboOnce`, বাকি
`onTurboLoad`। `script-inventory.md` এর section 2 এ mixed block-গুলোর
তালিকা আছে (৪৫টি সত্যিকারের mixed)।
