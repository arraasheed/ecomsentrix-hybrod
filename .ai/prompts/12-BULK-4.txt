### helper তিনটি (BULK-2/3 এর মতোই)

```js
window.onTurboLoad(fn)      // প্রতি পেজে — widget init (DataTable, select2, chart)
window.onTurboOnce(fn, key) // পুরো সেশনে একবার — event delegation
window.onTurboUnload(fn)    // পেজ cache হওয়ার আগে — destroy
```

### রূপান্তরের নিয়ম (অপরিবর্তিত)

| পেলে | করবে |
|---|---|
| `$(document).ready(function(){...})` | `window.onTurboLoad(function () {...})` |
| `$(function(){...})` | `window.onTurboLoad(function () {...})` |
| `$(document).on('click', sel, fn)` | `window.onTurboOnce(function () {...})` |
| `$('body').on('click', sel, fn)` | `window.onTurboOnce(function () {...})` |
| খোলা কোড যা DOM খুঁজে init করে | `window.onTurboLoad(...)` |
| শুধু `var x = "...";` | **স্পর্শ করবে না** |
| একই block-এ init + delegation | ভাগ করো (নিয়ম E) |

🔴 delegation কে `onTurboOnce` না দিলে যা হয় তা মাপা হয়েছে: handler
২৯ → ৪৬৪ (৮ navigation), এক ক্লিকে ৮টি POST, DB-তে qty ১ → ৮।

⚠️ block-এ Blade মান interpolate থাকলে (`{{ $x }}`) প্রতি পেজে source text
আলাদা হয়, duplicate detection কাজ করে না। তখন দ্বিতীয় আর্গুমেন্টে নাম দাও:
`window.onTurboOnce(function () {...}, 'coupon-code-copy');`
